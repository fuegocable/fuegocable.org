Hi! Bomba here.

After many months of work, I'm finally publishing **fuegocable**, an open-source project that aims to provide everything needed to give old, obsolete FireWire audio interfaces a new life as USB audio interfaces.

Some of these interfaces are sitting around collecting dust, even though they're still great pieces of technology, with multiple analog channels, preamps, and all kinds of connectivity. Maybe you have no trouble using your FireWire interface because you have a computer with the right port and the exact drivers needed to make it work properly. But that's not always the case. Some manufacturers have abandoned driver development, leaving users with no choice but to stick to obsolete operating systems or to desktop computers because modern laptops don’t have a FireWire port.

The idea behind this project is to overcome that obstacle. For now, [the best approach](/docs/intro/firewire-usage) — the most stable one, and probably the one that can be most easily adapted to different interface models — is to modify the interface itself by replacing its main microcontroller with an XMOS chip capable of implementing USB Audio.

This new microcontroller needs to communicate with the audio codecs, user interface components (such as rotary encoders, LEDs, and displays), MIDI ports, digital audio ports, and so on.

All of this requires firmware capable of handling those tasks, and the idea is for fuegocable to become a place where that firmware can be developed. The project's [GitHub repository](https://github.com/fuegocable/xmos-firmware) already contains the first version of the firmware, which currently implements the features required by the first modified interface: a [PreSonus FireStudio Project](/docs/modding-guides/presonus/firestudio-project).

More interfaces could be modified in the future. Each one needs to be reverse-engineered, analyzed, and modified. fuegocable could become a place where other interested people can contribute to these processes.

Checkout the project's documentation to known [what is fuegocable?](/docs/what-is-fuegocable).

There's a lot to create and develop, and hopefully the future will bring us stable, scalable solutions for modifying many more interfaces and keeping the music alive with them!

See you soon!
