## Guide

### Build firmware and flash it

Clone the [fuegocable XMOS firmware repository](https://github.com/fuegocable/xmos-firmware) and follow its README to build the firmware binary. From the repository root, configure and build the firmware for this board and interface:

```bash
cmake -B build
cmake --build build --target dxio_mc_3w_presonus_firestudio_project
```

Use an XTAG connected to the board's XSYS header to flash the firmware. USB DFU may also be an option, but it has not been tested.

***

### Prepare xmos board

This guide uses the [DIYINHK DXIO MC (3W)](/docs/technical-overview/supported-xmos-boards/dxio-mc-3w-diyinhk.mdx), but [other XMOS-based boards](/docs/technical-overview/supported-xmos-boards/) can also be used, as long as all the required Presonus Firestudio Project signals are connected to the appropriate XMOS chip ports. The board needs a **3.3V** supply. In this build, an MP1584-based module was connected to the board's 3.3V/5V/GND header.

This board usually comes with a USB connector already installed. Remove it to free up the USB port traces, the USB-C connector will later be mounted on the audio interface chassis and wired to the board.

***

### Remove components

To perform the mod, you need to remove a few components.
From the top side of the PCB, remove two capacitors, the TCD2210 MCU, and the FireWire connector that will be replaced by the USB-C port. Ideally, remove the connector farthest from the interface's power supply.
From the bottom side of the PCB, remove the multiplexer IC.

### Solder wire bridge

On the bottom side of the PCB, where the multiplexer was removed, make two wire bridges.

One of them bridges the multiplexer outputs /O0 and /O1. These carry the shared SPI chip-select signal for the ADC and DAC, and the SPI chip-select signal for the LED meters, respectively. This makes the converters' SPI chip-select signal available at the connector on the top side of the main PCB that connects to the meter PCB.

The other bridges the converters RST signal (which originally is a GPIO from the original MCU) to a connector on the top side of the main PCB (the one with the original MCU's UART 0).

Before soldering, apply Kapton tape to the PCB. Once the wires are soldered, secure them to the tape with cyanoacrylate. The tape keeps the glue off the PCB, so the mod can be reversed cleanly by removing the tape.

Take particular care with the digital audio signals (MCU MCLK0, MCU FCK0, MCU DO0_0, and MCU DI0_0). They form a TDM bus with clock lines, so all bus signals must arrive in sync, with as little interference as possible to minimize jitter. A ribbon cable with an IDC connector is recommended, with ground conductors interleaved between signal conductors in a G-S-G-S-G pattern so each signal has its own ground, and all wires should be the same length.

All but one of the audio bus signals can be tapped from one edge of some specific resistors, which makes soldering easier. MCU DI0_0 must be soldered directly to a trace on the original MCU footprint. This takes a little more care and experience, but is manageable.

### USB C Connector and mount

This interface uses one of the FireWire port openings in the chassis to mount the female USB-C port that connects to the host. [A 3D-printed mount](#) designed for that opening and a specific [female USB-C module](https://es.aliexpress.com/item/1005012109928489.html) is available to download and print. The module fits the chassis opening and the mount, and includes D+ and D- connections as well as resistors between certain USB-C pins to ensure a 5 V supply when using USB-C power sources.

### Final assembling

To finish the assembly, attach the XMOS board to the original PCB with durable double-sided tape. The 3.3V power module can be attached to an inside wall of the chassis.

Keep all the removed original components together in a small bag and store it inside the interface, so they stay with the device. If you ever decide to reverse the mod, all the parts will be there.
