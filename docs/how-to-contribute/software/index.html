Software

Submit any pull requests that you think would add value to any fuegocable repository. The main firmware of the project is available at https://github.com/fuegocable/xmos-firmware, and eventually satellite applications will be added to interface with other features of the devices, such as audio mixers and signal routers.

AI use​

Please use AI responsibly. Extremely long PRs developed without sufficient context developed by a human will be difficult to review and approve. AI is very useful, and this project uses it constantly, but always in a responsible way and with human judgment and awareness.
