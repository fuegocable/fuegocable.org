# Testing & bug reports

If you are a user of an audio interface modified with fuegocable, it is extremely important to share your feedback about how the mod is working. You can open an issue in the project's firmware repository, located at https://github.com/fuegocable/xmos-firmware, to describe bugs or suggest improvements in detail, so someone can review and implement them. The more detail and information you can provide in the issue, the better!
