# What is fuegocable?

fuegocable es un proyecto abierto para todos y sin fines de lucro que busca ser fuente de documentación y fuente de herramientas para modificar interfaces de audio con conexiones físicas antiguas u obsoletas (como Firewire) agregandoles conectividad USB para poder utilizarlas con hosts actuales como laptops con Windows 11.

muchas interfaces de audio de hace algunos años ofrecían únicamente conexión por Firewire (algunas también podían traer ADAT o SPDIF). muchas de esas interfaces dependen su funcionamiento en que el host posea puerto Firewire y en que pueda correr drivers que dejaron de actualizarse para los sistemas operativos modernos. existen algunas opciones para utilizar dichas interfaces con PCs en la actualidad, pero suele ser una tarea laboriosa, exclusiva para pc de escritorio o laptops con thunderbolt y que a veces necesita de versiones antiguas de sistemas operativos para correr los drivers sin problemas.

fuegocable se enfoca en modificar las interfaces de audio para quitar el microcontrolador principal de las mismas que se encarga de configurar y transmitir audio digital desde y hacia los codecs de audio a través de Firewire, para utilizar otro microcontrolador que realice las mismas funciones pero implementando USB Audio Client para obtener la mayor compatiblidad posible con cualquier sistema operativo que implemente USB Audio Host (windows, linux, os x, ios, android, etc)

en esta web se aloja la documentación necesaria para entender el funcionamiento de el mod de fuegocable y sus características como también las guías para modificar las interfaces soportadas por el proyecto. además, por su naturaleza open source, el sitio también es un lugar donde se puede centralizar el proceso de ingeniería inversa de interfaces aún no soportadas aportando contenido, documentación y experiencias de forma colectiva y comunitaria.
