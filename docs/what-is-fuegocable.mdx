# What is fuegocable?

fuegocable is an open project for everyone and non-profit that seeks to be a source of documentation and tools to modify audio interfaces with old or obsolete physical connections (such as Firewire) by adding USB connectivity to be able to use them with current hosts such as laptops with Windows, Mac OS X, Linux, Android phones, iPhones or any host that is USB Audio Class Compliant.

Many audio interfaces from a few years ago offered only Firewire connection (some could also bring ADAT or SPDIF). Many of those interfaces depend their operation on the host having a Firewire port and being able to run drivers that stopped being updated for modern operating systems. There are some options to use that interfaces with PCs today, but it is usually a laborious task, exclusive to desktop PCs or laptops with Thunderbolt and that sometimes needs old versions of operating systems to run the drivers without problems.

fuegocable focuses on modifying audio interfaces to remove their main microcontroller that is responsible for configuring and transmitting digital audio to and from audio codecs through Firewire, to use another microcontroller that performs the same functions but implementing USB Audio Client to obtain the greatest possible compatibility with any operating system that implements USB Audio Host (Windows, Linux, OS X, iOS, Android, etc).

This website hosts the necessary documentation to understand the operation of the fuegocable mod and its characteristics as well as the guides to modify the interfaces supported by the project. In addition, due to its open source nature, the site is also a place where the reverse engineering process of not yet supported interfaces can be centralized by contributing content, documentation and experiences in a collective and community way.
