# Diyinhk DXIO MC (3W)

The first board used in the fuegocable XMOS firmware. It is based on the XMOS XUF216 chip, providing good processing power since it is internally based on two XU208 cores. This model has internal flash memory for firmware storage.

This board is especially useful because it has a header for connecting an [XMOS XTAG 3 debug adapter](https://www.xmos.com/xa-xtag3), which makes firmware development and debugging easier.

Each port exposed on a pin of the PCB headers is identified in the silkscreen on the bottom of the PCB. This can be somewhat confusing at first, so the following image aims to clarify the board's pinout.

Currently, the XMOS hardware description for this board, present in the `.xn` file of the fuegocable firmware [dxio_mc_3w.xn](https://github.com/fuegocable/xmos-firmware/blob/master/boards/dxio_mc_3w/src/dxio_mc_3w.xn), defines specific roles for each bit of the available ports according to certain communication buses. This will probably change in the future, because in order for the fuegocable firmware to support multiple boards and their different hardware definitions, it would be preferable to define intermediate constants to configure the hardware for each audio interface in the most flexible and clear way possible.

### Debugging with XTAG

This board features a header for directly connecting an [XTAG 3](https://www.xmos.com/xa-xtag3) debugger. A VSCode extension, [XTC Tools](https://www.xmos.com/documentation/XM-014363-PC/html/installation/install-configure/install-tools/install_vscode.html), is also available and can be used in conjunction with the debugger to enable easy code testing and development.
